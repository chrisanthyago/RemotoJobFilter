# RemotoJob Filter Web

Webpage for RemotoJob Filter, a Chrome extension that allows you to filter job offers on RemotoJob website [remotojob.com](https://remotojob.com/) based on your preferences. The extension provides a user-friendly interface to select the desired filters and displays the filtered job offers in a clear and organized manner.

## Available at

Get it at [remotojobfilter.pages.dev](https://remotojobfilter.pages.dev/).

## Sections

1. **App** section highlights the benefits of using the extension, letting users download it and view its features.
2. **Enterprise** section showcases the company's capabilities, team members, and skills, as well allows users to contact team members.
3. **Products** section displays the available products with live-version and try-it-yourself links.
4. **About** section provides information about the creator and their expertise.
5. **Contact** section allows users to reach out for inquiries or support.

## Tech Stack

This single-page application (SPA) utilizes the W3.CSS framework for styling and layout, featuring a navigation bar and parallax images. Designed to be responsive and accessible across various devices, the project is built with HTML5, CSS3, and JavaScript, integrating Google Fonts for typography and Material Symbols for icons. Additionally, the site is optimized for performance and SEO through structured content and appropriate meta tags.
